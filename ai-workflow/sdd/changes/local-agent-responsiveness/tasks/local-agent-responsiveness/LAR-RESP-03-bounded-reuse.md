交付设计第 4.1 节，在完整生命周期基础上启用同一绑定的可选短期复用。验证代次、授权、账号、配置与项目身份，限制空闲 TTL/LRU，逐轮重新验证实际权限。补充综合验收和用户操作文档。

验收：连续两轮一次启动与初始化，无重复恢复；不同绑定不能复用；TTL/LRU、变更、取消、审批超时、异常退出和重启清理正确；迟到事件不串轮次；不确定输入不重发。相关离线、类型和 lint 检查通过，按真实证据报告收益与限制。

## 实现与验收证据

- 同一完整绑定的连续两轮共享一个原生进程，第二轮不再初始化或恢复 thread；每轮重新验证本机状态、账号、有效权限与 thread 元数据，并显式提交项目根目录和审批策略。
- 空闲池默认五分钟、最多两个进程，验证 TTL、LRU 与释放代次。模型、权限、指令、认证、CLI 或配置变化均不能沿用旧进程；来源无法验证或有存活工具后代进程时回退冷启动。旧轮次的取消和迟到事件不能影响新轮次。
- 停止、清空、归档、恢复、目标变更、撤销、异常退出和 Host 重启均有覆盖。中断的原生输入不重发；重启只恢复未完成的清理意图。重复历史清理使用相同运行快照收据，确认后的旧收据不能关闭后来的运行。
- 最终相关离线回归覆盖十四个测试文件，共四百九十七项通过。包含原生协议、安全隔离、启动竞争、缓存失效、取消、重试、共享正文归并及 Web/Mobile 状态投影；模型目录查询期间认证变化会使所有合并调用失效。
- 隔离 PostgreSQL 验收通过：使用迁移账号和受 RLS 约束的应用账号验证真实 API、Worker、加密凭据、配对授权、连续执行、释放、停止、清空、归档恢复、目标变更和重启恢复；临时数据库已删除，未使用应用现有数据库。
- adapters、core、local-agent、API、Web、Mobile 类型检查通过；本项最终修改后重跑 adapters 类型检查和相关十五个文件的 Biome 检查，均通过。
- 已安装 CLI 的无推理探针通过：配置、账号、指令来源、空闲 thread 及无工具后代检查成立，复用时无需新启动或恢复。探针没有提交模型输入，不构成真实模型正文响应时间或限流等待改善的测量。
- 浏览器 CI 场景已覆盖等待、公开摘要、重试与取消，并准备截图入口。后续真实浏览器手动验收确认等待、思考、连续对话和停止；Electron E2E 仍按仓库约定交给 CI 虚拟显示环境。没有新增数据库迁移。
- 三项实现及验收修复保存本地提交，未推送。源码中的生命周期复用仍默认关闭，按运维文档在 API/Worker 和 helper 更新且旧运行排空后启用。

## 真实环境验收补充

- 原生会话被其他 Codex 客户端持有写入者时，恢复会被拒绝，输入没有提交。维护操作保留原会话并派生独立分支后继续验收，没有自动抢占原写入者或重发失败输入。
- 发现终态与后代退出之间的竞争会使可复用进程过早关闭。新增短期后代夹具先复现失败；改为有界复核后，相关五组共六十二项回归通过，adapters 类型及三个修改文件的 Biome 检查通过。持续后台工具和进程所有权清理仍在回归覆盖内。
- 真实浏览器连续两轮使用同一原生进程，第二轮没有初始化或恢复，重新校验策略且保持上下文；公开阶段与答案独立。停止后网页临时状态消失，后台确认为取消，原生进程退出。
- 实测只作为验收样本，不承诺所有模型任务的固定响应时间，也不推断上游限流已经解决。运行证据和截图保存在私密运维记录中。

复盘：主要返工来自原生配置对象的键顺序不稳定，以及测试把首个活动事件当作输入已提交。配置规范化后计算指纹，恢复测试等待实际正文证据；并发失效测试使用显式门闩，避免靠固定延时猜测进度。后续继续优先用确定性协议夹具验证生命周期，再用无推理探针核对已安装 CLI，减少真实模型等待和费用。

部署复盘：基础镜像元数据查询与递归整理依赖目录增加了等待。复用与锁文件匹配的本机镜像，并只整理源码权限，可以避开这些额外开销。真实推理仍需保留小范围验收，以覆盖单纯初始化探针无法发现的写入者占用与终态清理竞争。

## 写入者占用复查

- 后续真实请求在 `thread/resume` 被另一客户端的存活写入者拒绝，尚未调用 `turn/start`。此前成功的连续对话及停止验收不代表原会话被其他客户端占用后仍能恢复；这一限制单独记录，不再将通用“已停止”提示当作取消证据。
- 将经过严格原生协议匹配的占用错误转换为提供商无关的安全代码。通过新增可空字段持久化代码，兼容旧版本读写；页面共享错误归一化区分失败、停止、不确定和占用，不转发原始原生诊断。
- 初始化失败返回前等待清理，避免下一条明确的新请求与旧进程清理竞争。占用不自动重试、不派生分支、不改原生引用，也不关闭其他客户端。
- 独立真实会话的执行、停止、停止后冷恢复及正常关闭后冷恢复通过，项目范围与权限配置保持一致。原受占用会话仍需由持有它的客户端释放；不能将独立会话的验收结果表述为原会话已恢复。
- 本次七组离线回归共二百二十一项通过，隔离 PostgreSQL 的 API/Worker 验收覆盖停止、占用、无输入重发、安全代码持久化及释放后的同会话继续。adapters、db、Web 类型检查通过；浏览器手动验证生产错误组件展示占用建议，CI 增加对应截图场景。补齐移动端既有本地执行设置翻译缺项，并验证新错误文案的所有语言资源。

复查复盘：首次并行检查与本机负载叠加，触发了夹具进程启动和短租约超时；减小验证并发后通过，没有放宽产品权限或原生超时。后续将真实占用错误、干净关闭后恢复和停止后恢复分开验收，避免把单个成功分支当成完整恢复证明。

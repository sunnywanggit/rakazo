# 生命周期、计时与发现缓存

- Design: [local-agent-responsiveness](../../design/local-agent-responsiveness.md)

交付设计第 4.2、4.3、5、6 节对应基础能力。扩展中立引擎生命周期，认证能力协商与幂等释放，协调清空、归档、删除、目标变更与撤销。增加单调阶段计时、带身份失效的版本和模型目录短缓存；复用默认关闭。

验收：旧 Host 404 正常降级；旧请求不启用复用；越权或变更绑定释放被拒绝；释放与启动按代次隔离；不泄漏原生引用与账号；发现查询合并、过期和失效正确，错误不缓存。

## 验收证据

- 生命周期、Host、原生驱动、设置协调与恢复测试通过；释放语义修正后四组共 37 项再次通过。此前扩大检查覆盖共享契约和多端事件归并，共 466 项通过。
- adapters、local-agent、API 类型检查通过。新增生命周期能力、显式请求标头和认证释放端点均兼容现有 v1 执行载荷；旧 Host 的 404 降级为冷启动，认证错误不降级。
- 释放保存不可变操作收据与当时运行的取消记录；未确认期间阻止新准入，确认后允许明确的新任务，重试旧收据不能取消新任务。原生引用与私密状态只在 Host 保留。
- 模型目录合并查询、认证变化失效、单调时钟过期与可执行文件版本缓存均通过假 CLI 验证。诊断只含阶段名与耗时，不含路径或账号。
- 复用仍默认关闭，本项仅建立完整生命周期和缓存基础。

复盘：主要时间用于区分“关闭空闲进程”和“永久撤销会话”。后者会破坏归档后继续对话；不可变释放收据与逐运行取消记录同时满足恢复和迟到请求隔离，应作为后续复用竞争测试的基础。
